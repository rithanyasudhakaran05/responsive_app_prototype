#  Ecstasy – Dessert Ordering App (Figma Prototype)

##  Project Overview
Ecstasy is a simple mobile UI prototype for a dessert ordering application designed using Figma.  
It demonstrates a smooth user flow from browsing desserts to placing an order.

---

##  Objective
To create a clickable interactive prototype that simulates a real-world food ordering experience with simple navigation and user interaction.

---

##  Tools Used
- Figma

---

##  Screens Included

### 1. Home Screen
- Displays "New In" and "Most Popular" sections  
- Shows dessert items with images and prices  

### 2. Product Screen
- Displays selected product details  
- Includes description and "Add to Cart" button  

### 3. Cart Screen
- Shows selected items  
- Displays pricing details  
- Includes "Checkout" button  

### 4. Order Success Screen
- Confirms order placement  
- Includes "Continue" button  

---

##  Prototype Flow

Home → Product → Cart → Order Success → Home

---

##  Features
- Clean and minimal UI  
- Clickable navigation  
- Smooth screen transitions  
- User-friendly layout  

---

##  User Testing
Basic testing was done by:
- Navigating through all screens  
- Verifying button interactions  
- Checking overall flow  

---

##  Outcome
- Built a functional interactive prototype  
- Learned screen linking and navigation in Figma  
- Improved understanding of UI/UX design flow  

---

##  Conclusion
This project demonstrates the creation of a simple and effective mobile app prototype using Figma, focusing on usability and clear navigation.
